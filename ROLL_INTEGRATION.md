# Броски из оружейной ленты (1.5.0)

Исследованы Forbidden Lands **13.0.5**, Roll Dialog Plus **0.7.1** и FL Firearms **0.4.6–0.4.7**. Лента предоставляет кнопку атаки; уклонение и парирование пока доступны только через прежний `api.rolls`.

| Операция | Штатный вызов | Поведение |
| --- | --- | --- |
| Атака удерживаемым оружием | `actor.sheet.rollGear(itemId)` | Сохраняет навык, бонус, урон и остальные метаданные оружия. |
| Уклонение через API | `actor.sheet.rollAction("dodge")` | Системный Move-бросок и профиль Dodge в RDP. |
| Парирование через API | `actor.sheet.rollAction("parry", itemId)` | Системный Melee-бросок и профиль Parry в RDP. |

`rollAction("attack", itemId)` обнуляет урон в этой версии системы и здесь не используется. RDP оформляет системный FBLRollHandler через render hooks; публичного метода открытия окна у него нет.

## Результат штатного вызова

`rolls.open(...)` открывает окно, но его Promise ждёт подтверждения броска. Он возвращает системный результат `{roll, message}`, а при закрытии без броска отклоняется с `Roll cancelled`. Это **не** Promise, возвращающий Application сразу после открытия.

```js
const rolls = game.modules.get("yze-combat-permission-fix")?.api?.rolls;
const state = rolls?.getState();
const weapon = state?.items.find(item => item.attack);
if (state?.available && weapon) {
  try {
    const result = await rolls.open({
      kind: "attack", actorUuid: state.actorUuid, itemId: weapon.itemId,
      expectedRevision: state.equipmentRevision,
    });
    // result приходит после броска; этот низкоуровневый API не оплачивает действие.
  } catch (error) {
    if (error.message !== "Roll cancelled") throw error;
  }
}
```

Проверяются текущий принадлежащий игроку Actor UUID, версия системы, возможность действовать, Item в руках, исправность и ревизия экипировки. Предмет сначала берут отдельной манипуляцией с выбранной стоимостью; атака не извлекает его автоматически.

## Оплата атаки лентой

Игрок выбирает цену, затем открывается штатное окно. Журнал намерения создаётся до окна; само открытие бесплатно. Тег `yzeWidgetIntent` добавляется только в параметры конкретного Application, синхронно при вызове системного листа. Привязка не ищет «следующее похожее окно».

При подтверждении обёртка ждёт резервирования выбранных native YZE Active Effects, затем вызывает сохранённый `executeRoll`. Существующие обработчики FL Firearms/RDP сохраняются. Метка `yzeWidgetAttack` попадает в options конкретного броска; сообщение проверяется по автору, Actor, Item, бою/раунду, идентификатору операции, а для synthetic Actor — также Scene/Token.

Повтор submit ждёт один Promise. Повтор подтверждения и Push не оплачивают атаку заново. GM может завершить журнал через createChatMessage, даже если клиент потерял ответ. Позднее подтверждение не расходует действие следующего раунда.

Закрытие до submit не оплачивается. Если окно закрыто во время ожидания оплаты, бросок не запускается, а собственный резерв возвращается. Отказ системного backend без сообщения также возвращает только эффекты этой операции. Если подходящее сообщение уже есть, отмена завершает журнал без возврата. При неопределённом результате интерфейс требует сначала проверить чат; новый бросок не создаётся автоматически.

Урон, таланты, модификаторы, Push, патроны, осечка, chat card и Dice So Nice остаются в штатном backend и его расширениях. Виджет не вызывает дополнительный расход патрона и не пересчитывает формулы.

## Проверки и границы

Unit-тесты покрывают отмену, дублирование submit, закрытие во время оплаты, смену Actor, точное подтверждение/Push, synthetic Scene/Token и возврат собственных эффектов. Chrome-стенд использует реальный класс FBLRollHandler/FBLRoll и тело rollGear из локальной системы 13.0.5; Documents, транспорт, генерация случайных костей и расход патронов в нём имитируются.

Это не проверка живого мира с двумя клиентами, RDP и Dice So Nice. Для приёмки открыть окно, закрыть его, подтвердить атаку, сделать Push и закончить раунд обычным игроком при подключённом GM. Исходный permission fix и отдельный socket перехода раунда сохранены.
